01

대회 개요

Task
K리그 경기 내 플레이 시퀀스의 마지막 패스 도착 좌표 (end_x, end_y) 예측.
좌표는 FIFA 공식 권장 규격 105 × 68m 그리드에 매핑된 상대 좌표. 패스 목적지는 경기 맥락 전체를 시계열로 이해해야 예측 가능한 고차원 문제입니다.
평가 지표
유클리드 거리 기반 MAE
√((pred_x - true_x)² + (pred_y - true_y)²) 의 평균.
x, y 오차를 동시에 최소화해야 하므로 두 방향을 별도 모델로 각각 예측하는 2-head 구조를 채택했습니다.

03

피처 엔지니어링

단순 좌표값이 아닌 경기 맥락을 담은 피처를 설계했습니다. Residual 예측 방식을 채택하여 end_x/y의 절댓값 대신 start 대비 변화량(dx, dy)을 예측함으로써 학습 안정성을 높였습니다.

설계 의도 왜 Residual(변화량) 예측인가. 절댓값(end_x)을 직접 예측하면 모델이 피치 전체 범위(0~105m)를 커버해야 합니다. 변화량(end_x − start_x)을 예측하면 대부분의 패스가 소규모 이동이라 분포가 0 근방에 집중되어 MAE 기반 학습이 더 안정적입니다. 최종 좌표는 start_x + pred_dx × 105 로 복원합니다.
그룹 1 — 현재 상태 피처 (Last Timestep)
피처명설명계산 방법
last_sx / last_sy 마지막 이벤트의 정규화된 시작 좌표 start_x / 105.0, start_y / 68.0
speed_last 마지막 시점의 이동 속도 √(dx²+dy²) / dt, dt 최소 0.01 클리핑
angle_last 마지막 이동 방향 (라디안) arctan2(dy, dx)
cat_type / cat_result 이벤트 종류 및 결과 범주형 인코딩 CatBoost는 문자열 그대로, LGBM/XGB는 LabelEncoder 후 정수 입력
cat_team_id / cat_player_id 팀 ID, 선수 ID 결측은 -1로 대체 후 범주형 처리
그룹 2 — Gap 피처 (이벤트 연속성)
피처명설명설계 의도
gap_x / gap_y 직전 이벤트의 end 좌표와 현재 start 좌표의 차이 연속 이벤트 간의 "점프"를 감지. 볼 소유권 전환 여부 신호
gap_dist gap의 유클리드 거리 √(gap_x²+gap_y²). 값이 크면 클리어런스/인터셉트 상황일 가능성
그룹 3 — 시계열 Lag 피처 (최근 K개 이벤트 요약)
피처명설명
sx_lag0~2 / sy_lag0~2 직전 3개 이벤트의 start 좌표 (가장 최근 = lag0)
speed_lag0~2 직전 3개 이벤트의 이동 속도
angle_lag0~2 직전 3개 이벤트의 이동 방향
prev1_type ~ prev3_type 직전 1~3번째 이벤트 타입 (범주형)
zone_x / zone_y 피치를 구역(공격/중원/수비, 왼쪽/중앙/오른쪽)으로 분류한 범주형 피처. CatBoost pseudo 재학습 시 추가 OOF 분석에서 구역별 패스 분포가 비균일(공격 55%, 수비 11%)함을 확인. 구역 정보가 모델에 맥락 제공
그룹 4 — 통계 피처 (선수 히스토리)
피처명설명설계 의도
player_spread 선수별 start 좌표 표준편차 평균 활동 반경 넓은 선수(미드필더) vs 좁은 선수(골키퍼) 구분. EDA에서 선수별 분산이 크게 다름을 확인
player_mean_x / _y 선수의 평균 활동 위치 포지션 근사치. x 평균이 높은 선수(공격수)는 전방 패스를 보내는 경향이 강함
team_attack_ratio 팀별 공격 이벤트 비율 (true_x > 70 패스 비율) OOF 분석(198경기)에서 게임별 공격 비율이 35.1%~74.1%로 2배 이상 차이. std=0.070으로 팀/경기마다 전술 성향이 뚜렷하게 다름을 확인

Pseudo Labeling

1차 CatBoost 모델로 Test set 예측값을 생성 → 이 예측값을 정답(pseudo label)으로 삼아 Train + Test를 합친 데이터셋으로 재학습. Test 데이터의 특성 분포를 학습에 반영해 domain gap을 줄이는 기법.

구현 주의사항: Pseudo label의 group을 -1로 설정하여 GroupKFold validation 시 이 데이터가 항상 train side에만 포함되도록 처리. OOF 계산은 원본 train 데이터 기준으로만 수행.

방법 1 — Monte Carlo Search
10만 회 랜덤 가중치 샘플링 후 OOF MAE가 가장 낮은 조합 선택. 구현이 단순하고 전역 최적해 탐색 가능. 가중치 합 = 1 제약 내에서 탐색.
방법 2 — Scipy SLSQP 최적화
scipy.optimize.minimize SLSQP 알고리즘으로 가중치 합 = 1, 각 가중치 ∈ [0,1] 제약 조건 하에서 MAE 최소화. 경사 기반으로 빠르게 수렴.

01
Residual 예측의 효과
end_x를 직접 예측하는 대신 변화량을 예측하는 방식이 학습에 유리합니다. 대부분의 패스가 작은 이동이라 타겟 분포가 0 근방에 집중되어 MAE 기반 학습에서 더 빠른 수렴과 안정성을 제공합니다.
02
GroupKFold의 중요성
같은 경기(game_id) 내 이벤트가 train과 valid에 섞이면 OOF 점수가 과도하게 낙관적으로 측정됩니다. 올바른 검증 설계가 앙상블 가중치 최적화의 신뢰도를 결정합니다.
03
Multi-Seed 앙상블
[42, 2024, 777] 3개 시드로 학습한 모델을 평균하는 것만으로 단일 시드 대비 유의미한 성능 향상이 있었습니다. 코드 주석에서도 "점수 향상의 치트키"로 표현될 만큼 효과적이었습니다.
04
Pseudo Labeling의 디테일
Test 데이터를 pseudo label로 활용할 때 group=-1 처리로 validation leak을 방지하는 세심한 구현이 필수입니다. 잘못 구현하면 OOF 점수가 부풀려져 앙상블 최적화가 틀어집니다.
05
도메인 피처의 힘
선수별 활동 반경(player_spread), 평균 위치(player_mean_x/y) 등 축구 도메인 지식에서 파생된 통계 피처가 모델 성능에 크게 기여했습니다. EDA로 확인한 선수별 활동 패턴 차이가 피처 설계의 근거가 되었습니다.
06
앙상블 최적화 결과
Monte Carlo vs Scipy SLSQP 두 방법을 모두 실험했습니다. 최종적으로 LGBM + CatBoost 2모델만으로도 4모델 전체 앙상블과 점수 차이가 없었습니다. 모델 수보다 다양성과 품질이 중요하다는 교훈을 얻었습니다.
