대회 개요

무엇을 예측했는가

경기 내 플레이 시퀀스를 입력으로 받아 마지막 패스의 도착 좌표를 예측했습니다. 좌표는 FIFA 공식 권장 규격 105 × 68m 그리드에 매핑된 상대 좌표입니다.

Task
end_x, end_y 예측

K리그 경기 내 플레이 시퀀스의 마지막 패스 도착 좌표를 예측합니다. 패스 목적지는 경기 맥락 전체를 시계열로 이해해야 예측 가능한 고차원 문제입니다.

평가 지표
유클리드 거리 MAE

√((pred_x - true_x)² + (pred_y - true_y)²)의 평균을 최소화합니다. x, y 오차를 동시에 낮추기 위해 두 방향을 별도 모델로 예측하는 2-head 구조를 선택했습니다.

탐색적 데이터 분석

분포와 오차 패턴에서 모델 설계 힌트를 찾았습니다

OOF 예측 결과 15,428개 에피소드를 직접 분석하여 좌표 분포, 오차 분포, 시퀀스 구조가 모델 설계에 어떤 영향을 주는지 확인했습니다.

패스 도착 x좌표 분포
55.0%

전체 패스의 55%가 공격 3분의 1 구역(70m 이상)에서 종료되었습니다. 평균 도착 x좌표는 68.5m로, 전진 패스 비중이 높다는 도메인 특성을 반영합니다.

패스 도착 y좌표 분포
35.1%

양쪽 사이드라인 근처에 전체의 35.1%가 집중되었습니다. 사이드 패스가 중앙 패스보다 약 1.8배 많은 구조입니다.

모델 오차 분포
27.5m+

절반 이상은 10.7m 이내로 예측하지만, 상위 10% 케이스는 오차가 27.5m 이상으로 커졌습니다. 롱패스와 측면 전환이 대형 오차의 주요 후보였습니다.

좌표 난이도 비교
x방향 MAE
8.37m
y방향 MAE
8.41m

y방향이 더 어려울 것으로 예상했지만, 실제로는 두 방향 모두 비슷한 난이도였습니다. y축은 사이드 쏠림, x축은 공격 방향 롱패스 오차가 서로 난이도를 맞췄습니다.

EDA에서 모델링으로 이어진 결정
시퀀스 길이최근 K=20개 이벤트만 사용하고, 짧은 시퀀스는 Zero-padding 처리
좌표 경계최종 예측 시 clip(0,105), clip(0,68)로 물리적으로 불가능한 좌표 방지
선수 정보player_spread, 평균 활동 위치 등 선수별 활동 반경 통계를 피처화
피처 엔지니어링

절댓값이 아니라 변화량을 예측했습니다

end_x/y의 절댓값을 직접 예측하는 대신, 마지막 start 좌표 대비 변화량(dx, dy)을 예측했습니다. 대부분의 패스 이동량이 0 근방에 모이기 때문에 MAE 기반 학습이 더 안정적이었습니다.

Residual 예측 방식
start + pred_delta

피치 전체 범위(0~105m)를 바로 맞히는 대신 변화량을 예측한 뒤 start_x + pred_dx × 105 방식으로 최종 좌표를 복원했습니다.

피처 설계 방향
맥락 + 도메인

마지막 이벤트 상태, 이벤트 간 gap, 최근 3개 lag, 선수·팀 통계 피처를 조합해 시계열 맥락과 축구 도메인 정보를 함께 반영했습니다.

피처 그룹 주요 피처 설계 의도
현재 상태 last_sx, last_sy, speed_last, angle_last 마지막 이벤트의 위치와 이동 방향을 직접 반영
Gap 피처 gap_x, gap_y, gap_dist 직전 이벤트 종료 좌표와 현재 시작 좌표 간 점프를 감지
Lag 피처 sx_lag0~2, speed_lag0~2, prev1_type~prev3_type 최근 플레이 흐름과 이벤트 타입의 연속성을 요약
통계 피처 player_spread, player_mean_x/y, team_attack_ratio 선수 역할과 팀 전술 성향을 모델이 간접적으로 학습하도록 설계
모델링 파이프라인

검증 누수를 막고, 모델 다양성을 확보했습니다

같은 경기의 이벤트가 train과 valid에 섞이지 않도록 GroupKFold를 적용했고, GBDT 3개 모델과 CNN 모델을 결합해 서로 다른 귀납 편향을 확보했습니다.

01
Residual 예측의 효과

변화량을 예측하자 타겟 분포가 0 근방에 집중되어 MAE 기반 학습이 더 안정적이었습니다.

02
GroupKFold의 중요성

같은 경기 이벤트가 train과 valid에 섞이는 문제를 막아 신뢰할 수 있는 OOF를 만들었습니다.

03
Multi-Seed 앙상블

3개 시드 평균만으로도 단일 시드 대비 유의미한 안정화 효과가 있었습니다.

04
Pseudo Labeling 디테일

validation leak을 방지하는 구현 세부가 OOF 신뢰도와 최종 점수를 좌우했습니다.

05
도메인 피처의 힘

선수별 활동 반경과 평균 위치 같은 축구 도메인 통계 피처가 모델 성능에 기여했습니다.

06
