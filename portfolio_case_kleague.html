피처 엔지니어링

어떤 피처가 핵심이었는가

도메인 지식(전술·포지션·흐름)을 수치로 표현하는 것이 목표. 선수 포지션 정보가 없어도 통계로 근사 가능.

★ 핵심 설계 — Residual 예측
end_x 직접 예측 → 0~105m 전체 커버 필요, 분산 큼
Residual(end_x − start_x) 예측 → 분포가 0 근방에 집중, 학습 안정성 향상. EDA에서 발견한 중앙 회귀 현상의 해결책.
Group 1 · 현재 상태
직전 이벤트의 공간 정보
last_sx / last_sy — 직전 이벤트 좌표
speed_last / angle_last — 이동 속도·방향
cat_type / cat_player — 이벤트·선수 범주
Group 2 · Gap 피처
볼 소유권 전환 감지
gap_x / gap_y — 이전 이벤트와 위치 차이
gap_dist — 갭 거리 (볼 탈취 신호)
큰 gap = 볼 소유권 전환 가능성 → 패스 방향 크게 변화
Group 3 · Lag 피처 (K=20)
시계열 흐름 — 직전 20개 이벤트
sx/sy lag0~2 — 위치 3연속 이력
speed/angle lag0~2 — 속도·방향 이력
prev1~3_type — 직전 이벤트 타입 패턴
Group 4 · 통계 피처
선수 활동 반경 근사
player_spread — 선수들 간 공간 분포 (포지션 대용)
player_mean_x / player_mean_y — 팀 무게중심
선수 포지션 정보 없이 통계로 근사 — 도메인 지식 활용

앙상블 전략

성능을 끌어올린 3가지 전략

단순히 모델을 합치는 것이 아닌, 각 전략이 왜 필요한지 명확한 이유 존재.

Multi-Seed 앙상블
Seeds [42, 2024, 777] 3개로 학습 후 평균
트리 기반 모델의 랜덤성에서 오는 분산을 줄이는 가장 쉽고 효과적인 방법. 같은 하이퍼파라미터로 시드만 바꿔도 OOF MAE 개선.
Pseudo Labeling
Test 데이터 분포를 학습에 반영
01
1차 모델로 Test 예측값 생성
CatBoost OOF 예측 → pseudo label 생성
02
Train + pseudo Test 합쳐 재학습
group=-1 처리로 validation leak 방지
03
OOF는 원본 train만으로 계산

제약 최적화로 정밀 탐색 (합=1, 각≥0)

회고

솔직한 평가

잘 된 점
검증 설계가 전부다
GroupKFold 없이는 OOF가 낙관적 → 앙상블 가중치 최적화 전체가 틀어진다는 것을 직접 경험.
모델 수보다 다양성
4모델 전체 = LGBM+CatBoost 2모델. 모델 수를 늘리는 것보다 각 모델의 귀납 편향 다양성이 앙상블 효과를 결정.
도메인 지식이 피처를 만든다
player_spread, player_mean_x — 선수 포지션 데이터가 없어도 통계로 근사 가능. 도메인 이해가 피처 품질을 결정.
보완할 점
중앙 회귀 현상 미해결
y<5 케이스의 10m 과대추정을 발견했지만 별도 처리 미완.
→ 개선극단값 케이스 별도 모델 또는 후처리 로직 추가
CNN 성능이 트리에 못 미침
ResidualBlock + SE + AttentionPooling을 적용했지만 MAE 14.45m으로 트리 계열에 뒤짐.
→ 개선Transformer 기반 시계열 모델(TSMixer 등) 시도
Pseudo Label 노이즈
CatBoost 1차 예측을 pseudo label로 사용해 초기 오차가 누적될 가능성 존재.
→ 개선신뢰도 높은 예측(MAE 낮은 케이스)만 선별 사용
