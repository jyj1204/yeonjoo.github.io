🔍 조회는 많은데 안 팔린 상품 903개 발견
조회 100회 이상이지만 장바구니·구매가 단 0건인 상품이 903개. 전환이 극도로 낮은 구조적 문제를 확인하고 가설을 2가지 설정.
📉 구매 전환율 0.84% — 글로벌 평균 절반 이하
글로벌 이커머스 평균(2~3%)의 절반에도 못 미치는 전환율. 알고리즘 개선 전 근본 원인 파악이 선행되어야 함.
💡 분석 방향: 2가지 가설
가설 1 상품 자체의 문제일까? (품절·정보 누락)
가설 2 이상 사용자가 지표를 왜곡하는 걸까?
가설 1 "조회는 많은데 안 팔리는 건 상품 자체에 문제가 있는 건 아닐까?"

조회 100회 이상, 장바구니·구매 0건인 903개 상품을 확인.
추천이나 마케팅 문제라면 여러 상품에 걸쳐 랜덤하게 분포해야 함. 하지만 결과는 다름.

903개 상품 원인 분류
원인별 상세 분포
품절 상품 제거 전·후 추천 성능 비교

살 수 없는 상품을 추천 후보에서 제거했을 때 Precision@10이 어떻게 바뀌는지 확인

✅ 가설 1 검증 결과
903개 상품 중 78.7%가 품절 상태, 13.3%가 상품 정보 미등록으로 처음부터 구매 자체가 불가능. "추천이나 마케팅의 문제"가 아니라, 데이터 품질 문제. 품절 상품을 추천 후보에서 제거하는 것만으로 Precision@10이 0.005 → 0.006으로 개선.
가설 2 "이상하게 활동하는 사용자가 전체 지표를 왜곡하는 건 아닐까?"

보통 사용자는 사이트에서 1~2번 정도 행동하고 떠남.
그런데 일부 사용자는 구매도 장바구니도 없이 '보기'만 수십~수백 번 반복. 이런 사용자가 전체 조회 수를 부풀려 전환율을 실제보다 낮아 보이게 만들 수 있음.

이상 사용자 정의 기준 3단계
기준조건의미
엄격 (strict)100번 이상 행동, 구매 0, 장바구니 거의 0누가 봐도 이상한 극단적 사용자
중간 (medium) ← 채택50번 이상 행동, 구매 0, 장바구니 매우 적음상위 약 0.1% 수준의 과도한 활동
느슨 (loose)20번 이상 행동, 구매 0, 장바구니 적음상위 약 0.5% 수준

제거할수록 전환율이 소폭 상승하지만 극적인 변화는 없음 — 분모(조회수) 왜곡의 영향

✅ 가설 2 검증 결과
이상 사용자를 제거하면 전환율이 소폭 상승 (0.84% → 최대 0.90%). 하지만 실제 구매 건수와 "장바구니 → 구매" 비율은 거의 그대로. 즉, 이상 사용자는 구매를 막은 게 아니라 '조회 수(분모)'를 부풀려서 전환율을 실제보다 낮게 보이게 만드는 구조. 제거 효과가 작으므로, 중간 기준 적용 후 가설 1(품절 제거)을 우선 해결책으로 채택.
Step 2.
매출 상승 전략 — 추천 알고리즘 비교

정제된 데이터로 5가지 추천 방식 비교

과거 데이터(train)로 추천 후보를 만들고, 이후 기간(test)에 실제 장바구니·구매 상품이 추천 목록에 있었는지로 점수 산출.

Precision@10 비교 (상위 10개 추천 기준)

추천한 10개 중 실제로 구매·장바구니에 담긴 비율. 높을수록 좋은 추천.

Hit Rate 비교

추천 중 하나라도 맞은 사용자 비율

Recall 비교

실제 관심 상품 중 추천에 포함된 비율

💡 핵심 인사이트: 상위 10개 추천에서는 '판매 가능 + 인기순'이 1위
복잡한 개인화 알고리즘이 아니라, "품절 상품을 추천 후보에서 빼는 것"만으로 세 가지 지표가 모두 개선. 다만 추천을 20개까지 넓히면 관심 카테고리 기반 추천이 더 좋은 결과를 보임. 즉, 상위 노출 영역에는 판매 가능한 인기 상품을, 더 넓은 영역에는 개인 관심사 기반 추천을 쓰는 것이 합리적.
Step 2.
매출 상승 전략 — A/B 테스트 설계

추천 영역 개선, 실제로 효과가 있는지 검증하기

오프라인 분석 결과를 바로 적용하지 않고, 실제 사용자를 대상으로 비교 실험을 설계함.

A그룹 (대조군, 50%)
판매 가능 + 인기순 추천
품절 상품 제거 후 전체 인기 기준으로 추천. 오프라인 평가에서 최고 성능을 기록한 기준선.
B그룹 (실험군, 50%)
판매 가능 + SVD 개인화 추천
품절 상품 제거 + 사용자 구매 이력 기반 SVD 협업 필터링 개인화 추천 적용.

실험 전에 미리 정해둔 규칙

실험을 멈추는 기준
구매 전환율이나 "장바구니 → 구매" 비율이 기존보다 눈에 띄게 나빠지거나, 품절 상품이 추천에 노출되는 일이 생기면 실험을 즉시 중단하고 이전 방식으로 되돌림.
Step 3.
결론

프로젝트 결론 및 인사이트

🏷️
가설 1 — 상품 데이터 품질 문제
조회는 많은데 안 팔린 상품 903개의 78.7%는 품절 상태. 추천 알고리즘이 아닌 상품 데이터 관리가 우선 과제.
👥
가설 2 — 이상 사용자의 지표 왜곡
이상 사용자 제거 시 전환율이 소폭 개선되지만, 구매 건수 자체의 변화는 미미함. 분모(조회수)를 부풀려 지표를 낮게 보이게 만드는 구조.
🎯
핵심 인사이트 — 데이터 품질 우선
모델 고도화 전에 데이터 품질 점검이 선행 필요. '품절 제외' 필터 하나가 Precision@10 기준 가장 효과적인 개선.
프로젝트 주요 성과
  • 가설 1 검증전환 불가 상품 903개 중 78.7%가 품절임을 확인 — 데이터 품질 문제로 귀결
  • 가설 2 검증이상 사용자 제거 시 전환율 소폭 상승 (0.84%→0.90%), 구매 건수 자체는 변화 미미
  • 알고리즘 비교5가지 추천 알고리즘 오프라인 평가 — '판매 가능 + 인기순'이 상위 10개 기준 최고 성능
  • A/B 테스트 설계핵심·참고·안전장치 지표 정의, 실험 전 기준 확정, 중단 기준까지 완전 설계
  • 제약 사항실제 A/B 테스트 미실시 (오프라인 시뮬레이션). 실사용 데이터 확보 시 온라인 검증 필요

프로젝트 회고

잘한 점
  • ✓
    가설 기반 분석 접근
    알고리즘부터 개선하지 않고 "상품 문제"와 "사용자 왜곡" 두 가설을 먼저 세운 뒤 데이터로 검증하는 순서를 지킴.
  • ✓
    이상 사용자 기준의 근거화
    단일 기준을 임의로 정하지 않고 엄격·중간·느슨 3단계로 나눠 효과를 비교한 뒤, 중간 기준을 채택하는 근거를 데이터로 제시.
  • ✓
    오프라인 평가 후 A/B 테스트 설계
    알고리즘 비교를 오프라인 시뮬레이션으로 먼저 진행한 뒤, 가드레일 지표·중단 기준까지 포함한 실험 설계로 이어짐.
  • ✓
    데이터 품질 문제를 먼저 발견
    전환율 저하의 원인이 알고리즘이 아닌 품절 상품 포함이었다는 점을 데이터로 확인하고, 해결 우선순위를 조정할 수 있었음.
아쉬운 점
  • △
    실제 A/B 테스트 미실시
    오프라인 시뮬레이션에서 멈춰 추천 개선이 실제 매출에 얼마나 영향을 줬는지 온라인 검증이 이루어지지 않음.
  • △
    매출 금액 데이터 부재
    구매 건수는 있지만 실제 금액 데이터가 없어 CLV나 매출 기여도 분석으로 연결하지 못함.
  • △
    이상 사용자의 실체 미확인
    봇인지, 내부 사용자인지, 특정 행동 패턴의 일반 사용자인지 확인하지 못해 제거 결정의 근거가 다소 약함.
  • △
    품절 상품 포함 원인 미추적
    왜 품절 상품이 추천에 계속 포함됐는지 시스템 레벨 원인(재고 연동 누락, 업데이트 딜레이 등)을 확인하지 못함.
