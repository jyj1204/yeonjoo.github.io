Data Analysis Project · Warehouse Robot Delay Study

창고 로봇 시스템 출고 지연 원인 분석

250개 창고 · 250,000건 · EDA → 모델링 → 경보 규칙 → 군집화 → PSM 인과 검증

Overview Analysis Design Findings Visuals Action Limits

프로젝트 개요

이 프로젝트는 “창고 운영에서 어떤 조건이 겹칠 때 다음 30분 출고 지연이 커지는가?”를 분석한 작업입니다. 단순히 높은 상관 변수를 찾는 데서 끝내지 않고, 가설을 세우고 반례를 확인하며 결론을 수정한 과정을 보여주는 포트폴리오형 분석입니다.

250,000250개 창고 × 1,000 시나리오 × 25 스냅샷
19.0분다음 30분 평균 출고 지연 평균값
715분극단적 수요 폭증 케이스 최대 지연
3번분석 과정에서 수정된 핵심 결론
타겟 변수

avg_delay_minutes_next_30m를 기준으로 다음 30분 평균 출고 지연을 설명했습니다.

핵심 메시지

지연은 단일 원인이 아니라 idle, 배터리, 혼잡, pack 병목이 함께 누적될 때 폭발했습니다.

분석 방향

원인 탐색에서 운영 전략까지 연결하기 위해 EDA, 모델링, 경보, 군집화, PSM을 순차적으로 사용했습니다.

분석 설계

  • EDA로 idle, 배터리, 혼잡, 레이아웃별 지연 패턴 탐색
  • 목적에 맞게 crisis_actual, snap_idx, alarm_cond, consec_alarm 변수 생성
  • LightGBM과 GroupKFold로 창고 단위 누출을 막고 변수 중요도 확인
  • 연속 경보 규칙과 ML 스코어를 비교해 실용 임계값 검토
  • K-Means로 250개 창고를 운영 특성별 유형으로 분류
  • PSM으로 hub_spoke 지연이 레이아웃 때문인지 운영 때문인지 검증
  • 반례 창고를 따로 확인해 EDA가 놓친 pack 병목 재검증
  • 위기 직전 6스냅샷을 추적해 단일 시점 경보의 한계 확인
  • 6개 운영 유형별 개입 우선순위 매트릭스 구성
  • 개선 효과는 가정 기반 시뮬레이션으로 상대 우선순위만 제시

핵심 발견

1. idle 30%는 1차 방어선

idle 최저 구간 평균 지연은 36.3분, 최고 구간은 5.5분으로 6.6배 차이가 났습니다. 30% 아래에서 지연이 고착됐습니다.

2. 배터리는 연쇄 반응의 시작점

방전과 충전 대기의 상관계수는 r=0.949였습니다. 저배터리 10% 초과 시 추가 지연이 커지고, 노후 배터리는 +7.0분 영향을 보였습니다.

3. 혼잡은 단일 요인 중 최대 영향

혼잡 최저·최고 구간 차이는 +24.8분이었고, 교착 상태는 39.3분으로 단순 고장 35.3분보다 더 심각했습니다.

4. pack_utilization은 숨은 병목

상관계수는 0.105로 낮았지만 모델 중요도 1위였습니다. 저가동과 고가동 모두 지연이 커지는 U자형 패턴이 확인됐습니다.

5. hub_spoke는 원인이 아니었다

단순 비교에서는 +3.69분, p=0.007이었지만 운영 조건을 통제한 PSM 후 -0.55분, p=0.783으로 효과가 사라졌습니다.

6. 경보는 순간보다 누적을 봐야 한다

규칙 기반과 ML 모두 Precision이 0.113~0.118 수준에 머물렀습니다. 위기는 6스냅샷 전부터 신호가 쌓이는 누적 현상이었습니다.

검증과 한계

GroupKFold 검증

같은 창고의 스냅샷이 학습과 검증에 동시에 들어가지 않도록 창고 단위로 분리했습니다. OOF RMSE는 21.77분, R²는 약 0.54였습니다.

PSM 결론은 잠정적

매칭 후 일부 공변량 균형이 완벽하지 않아 hub_spoke 효과 없음은 현재 데이터 범위의 잠정 결론으로 해석했습니다.

개선 효과는 상대 비교

전체 적용 시 19.0분 → 4.1분 추정은 가정 기반입니다. 절대 금액보다 배터리 사전 충전의 우선순위가 핵심입니다.
