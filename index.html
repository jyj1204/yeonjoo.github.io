Project 01 · Root Cause Analysis

창고 로봇 시스템 출고 지연 원인 분석

250개 창고의 로봇 운영 데이터를 분석해 출고 지연이 발생하는 구조를 추적했습니다. 단순히 지연과 상관이 높은 변수를 찾는 데서 멈추지 않고, EDA, 예측 모델, 경보 규칙, 군집화, PSM 인과 검증을 연결해 운영 개선 우선순위까지 도출했습니다.

PythonPandasLightGBMGroupKFoldK-MeansPSM
250,000운영 스냅샷 데이터
6.6xidle 최저/최고 구간 지연 차이
21.77분LightGBM OOF RMSE
p=0.783PSM 후 hub_spoke 효과 소멸

문제 정의

분석 질문

창고 운영에서 어떤 조건이 겹칠 때 다음 30분 평균 출고 지연이 커지는가?

데이터 범위

250개 창고 × 1,000개 시나리오 × 25개 스냅샷으로 구성된 250,000건 데이터를 사용했습니다.

타겟 변수

avg_delay_minutes_next_30m를 기준으로 지연 원인과 위험 창고를 분석했습니다.

분석 흐름

  • EDA
  • Feature Engineering
  • LightGBM Modeling
  • Alert Rule Test
  • K-Means Clustering
  • PSM Causal Check
  • Counterexample Review
  • Time-Series Pattern
  • Priority Matrix
  • Action Plan

핵심 발견

idle은 1차 방어선

idle 비율이 30% 아래로 떨어질 때 지연이 급격히 고착되며, 최저/최고 구간의 지연 차이는 6.6배였습니다.

pack_utilization은 숨은 병목

선형 상관계수는 0.105로 낮았지만, 모델과 반례 분석에서 U자형 병목 패턴이 확인됐습니다.

레이아웃보다 운영이 문제

hub_spoke는 단순 비교에서 +3.69분이었지만, PSM 후 -0.55분으로 효과가 사라졌습니다.

경보 규칙의 한계

임계값 조합과 ML 스코어 모두 Precision이 약 0.12에 머물러 단일 시점 경보의 한계를 확인했습니다.

위기는 누적된다

위기 직전 6스냅샷 전부터 혼잡이 높고 idle이 낮은 상태가 유지되어 추세 기반 감지가 필요했습니다.

개입 우선순위 도출

250개 창고를 6개 운영 유형으로 나누고, 배터리 사전 충전과 pack 60~80% 유지 전략을 제안했습니다.

시각화 자리

운영 우선순위

우선순위 유형 핵심 조치 목표
1 즉시개입형 경로 재배정, 충전 스케줄 긴급 조정 idle 30% 회복
2 배터리위기형 저배터리 10% 기준 사전 충전 충전 대기 감소
3 포장병목형 포장 부하 분산, pack 60~80% 조정 숨은 병목 완화
